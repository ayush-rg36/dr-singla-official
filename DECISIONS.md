## 2026-09-16 14:00 — Hide ElevenLabs "Powered by" branding on nephro-life widget
**Decision:** Wrapped the `<elevenlabs-convai>` tag in `artifacts/nephro-life/index.html` in a `.convai-wrap` div: `position:fixed; height:90vh; overflow:hidden` on the wrapper, widget itself shifted `bottom:-34px` inside it (mirrored to `left:0` since this widget uses `placement="bottom-left"`).
**Why:** ElevenLabs' shadow DOM always renders "Powered by ElevenAgents" text with no official CSS hook or hide toggle on the free plan — shadow DOM blocks external selectors from targeting it directly. Two rejected alternatives: (1) a short clip box hides the text but clips the expand-on-click call panel too (no room to grow); (2) a color-matched overlay patch hides the text but breaks visually against different section backgrounds (light body vs dark footer). Tall wrapper + fixed-pixel shift solves both — real clip (works over any background), and the panel still has 90vh of room to expand upward. Verified live (click-tested) on a different project using the same agent widget; not live-verified on this specific repo since it's a pnpm monorepo requiring a full `pnpm install` to spin up.
